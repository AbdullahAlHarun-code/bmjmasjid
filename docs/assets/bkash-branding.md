# bKash branding on this site

## Current presentation

No redistributable official bKash logo file with a clear project-safe license was available at implementation time.

The Support page therefore uses the temporary wordmark text **বিকাশ** styled with bKash’s commonly published brand pink (`#E2136E`), without implying merchant certification, partnership, or an integrated payment gateway.

## When replacing

If the project owner obtains a permitted official asset:

1. Place the file under `public/images/brand/` (SVG preferred).
2. Preserve original proportions and brand colours.
3. Update `BkashDonateCard` to render the image instead of the text wordmark.
4. Record the exact source URL/license here and the date obtained.

## Do not

- Publish wallet avatars, usernames, or screenshots from bKash
- Claim “official partner”, merchant QR, or gateway integration from branding alone
